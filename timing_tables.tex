\paragraph{Data notes.}
The Unified GIPC values and the nine-case wall times are taken from
\texttt{stage61\_nine\_main\_timing\_profile.md}.  The current DiffIPC Fig.~1
values are parsed from the latest aligned rerun log.  The Fig.~15, Fig.~18,
and Fig.~21 values use the accepted-result prefixes of their saved logs.  The
DiffIPC Fig.~10 phase values come from the earlier 36-record log at
\texttt{20260825\_original\_settings/fig10/run.log}; the selected 100-step
dynamic remesh result has no saved per-phase profiler log.  Thus the Fig.~10
speedup is a phase-level comparison, not a claim about the total wall time of
the selected 100-step run.  A speedup above one means Unified GIPC is faster;
the Fig.~10 value below one means that it is slower for this phase profile.
